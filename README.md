# 랜덤 체력운동

태권도장·체육관 수업에서 쓰는 체력운동 진행 도구입니다. 슬롯머신이 돌아가서
다음 운동을 뽑기 때문에, 관장이 정한 순서가 아니라 **뽑기로 정해진 것**이 되어
아이들이 훨씬 잘 따라옵니다.

## 받는 곳

**[다운로드 페이지](https://chalkak-app.pages.dev/workout)**

또는 [최신 릴리스](https://github.com/chalkak-soft/random-workout/releases/latest)에서
`RandomWorkout.zip` 을 받으시면 됩니다.

설치가 필요 없습니다. 압축을 풀고 `랜덤체력운동.exe` 를 실행하세요.

## 어떤 프로그램인가

- 운동마다 **확률과 시간**을 따로 정합니다. 확률 합계를 100에 맞추면 넣은 숫자가 곧 확률입니다
- **종료** 를 켠 줄이 뽑히면 그 자리에서 판이 끝납니다. 언제 끝날지 모르니 끝까지 집중합니다
- 진행자 창(노트북)과 디스플레이 창(TV)이 따로 열립니다
- 배경음악·돌아가는 소리·뽑힌 소리·판 끝 소리를 각각 넣을 수 있습니다
- 스페이스바와 무선 프리젠터(PageUp/PageDown)로 멀리서 진행할 수 있습니다

## 무료로 쓸 수 있는 범위

설치하고 처음 켠 날부터 **30일 동안 모든 기능**을 제한 없이 쓰실 수 있습니다.
신청이나 코드 없이 자동으로 시작됩니다.

30일이 지나도 프로그램은 계속 쓰실 수 있습니다. 운동 목록 하나를 고쳐 가며
쓰는 방식이 되고, 배경음악도 그대로 나옵니다.

프리미엄(**20,000원 · 무제한**)으로 열리는 것:

- **운동 목록 프리셋** — 유치부·초등부·성인부 레벨별 + 줄넘기·태권도 종목별 추가
- **배경영상** — 원하는 영상을 배경으로 (아이돌 영상, 무대 영상 등)
- **우리 도장 로고** — 화면 구석에 우리 도장 이름

사진 자동분류 프로그램 **찰칵정리**를 구독 중이시면, 구독 기간 동안 프리미엄을
무료로 쓰실 수 있습니다. 아래 채널로 말씀만 주세요.

자세한 사용법은 압축 파일 안의 `1. 먼저 읽어주세요.txt` 에 있습니다.
